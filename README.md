# Ритуал Мольфара: гейміфікований лендинг для Магнію Гліцинату

Тестове завдання: максимально конверсійна посадкова сторінка з квізом і гейміфікацією + 3 фото-креативи (і бонусне відео) у стилі сайту [Лавка Мольфара](https://lavka-molfara.com.ua/mahnii-hlitsynat-khelat-bishlitsynat-120-kapsul-1084).

**Демо:** https://serjikcod4.github.io/lavka-molfara-landing/

## Як механіка підвищує конверсію

Уся сторінка й реклама побудовані як одна воронка «Ритуал Мольфара»: **тест → карта → скриня → рівень → замовлення**.

1. **Квіз із 7 питань** працює як серія мікрозобов’язань: людина, яка вже 7 разів натиснула кнопку й отримала персональну «карту» з поясненням свого стану, охочіше робить наступний крок. Результат персоналізує оффер: не «купіть магній», а «ось чому саме тобі і який формат».
2. **Скриня Мольфара** відкривається після тесту (3 дотики). Подарунок обирається заздалегідь і закріплюється на 15 хвилин, тож сприймається як уже «свій». Таймер чесний: коли він спливає, вибір скидається, і подарунок треба обрати знову.
3. **Рівні Учень / Знахар / Мольфар** з прогрес-баром «до наступного рівня +1 🎁» ведуть до форматів 120 і 180 капсул і піднімають середній чек. Ціна за день однакова (≈27 грн), тож апсейл не виглядає переплатою.
4. **Шкала «Сила Мольфара», руни, досягнення й exit-intent** утримують увагу та повертають тих, хто збирається піти.
5. **Довіра**: лише дозволені формулювання для магнію (сприяє нормальній роботі нервової системи, м’язів, зменшенню втоми), позначка «Дієтична добавка», питання про протипоказання в квізі (за протипоказань сторінка пропонує консультацію замість покупки), оплата при отриманні, Telegram з −5%.

Креативи обіцяють рівно те, що людина бачить на сторінці (тест, скриня, рівні), тому між рекламою та лендингом немає розриву очікувань.

## Налаштування

Усі бізнес-параметри в об’єкті `CONFIG` на початку скрипта в `index.html`: ціни, подарунки, знижка Telegram, тривалість броні, посилання.

- `webhookUrl`: вставте URL вебхука CRM / SendPulse, і форма надсилатиме ліда (ім’я, телефон, формат, подарунки, архетип, індекс, усі відповіді квізу, UTM-мітки, referrer). Поки порожньо, працює демо-режим (лід виводиться в консоль).
- UTM, `fbclid`, `gclid` зберігаються з першого заходу.
- Точка входу з реклами: `?entry=chest` (креатив «Скриня» — скриня відкривається одразу, без квізу), `?entry=quiz`, `?entry=levels`; або те саме значення в `utm_content`.
- Telegram-кнопки передають у бот SendPulse формат, ціну, подарунки, карту квізу та UTM, як це робить сайт.
- Якщо вебхук недоступний, форма показує помилку з кнопкою Telegram і зберігає лід локально (не губить його мовчки).

## Аналітика

Події пишуться в `window.dataLayer` (GA4 через GTM) і в `fbq` (Meta Pixel), якщо він підключений:
`lm_quiz_start`, `lm_quiz_answer`, `lm_quiz_complete`, `lm_chest_open`, `lm_gift_select`, `lm_level_select`, `lm_forms_guess`, `lm_timeline_move`, `lm_order_view`, `lm_lead_submit`, `lm_telegram_click`, `lm_exit_intent_show`, `lm_achievement`, `lm_share`.

## Структура

```
index.html                 сторінка (HTML + CSS + JS, без фреймворків)
img/                       зображення (WebP)
fonts/                     Unbounded + Ubuntu (як на сайті), self-hosted
creatives/creative-*.png   3 фото-креативи 1080×1350
creatives/video-ritual-9x16.mp4   відео-креатив 15 с, 1080×1920
creatives/creative.html, video.html   джерела креативів (текст накладено кодом)
scripts/build_standalone.py          збирає один HTML-файл з усіма ресурсами
```

`python3 scripts/build_standalone.py` створює `dist/lavka-molfara-landing.html`, який відкривається без інтернету.

## Як зроблено

- Сцени для креативів і сторінки згенеровано в ChatGPT за референсом реального фото баночки; ілюстрації карт — там само в одному стилі.
- Текст на креативах накладено HTML/CSS шрифтами бренду (Unbounded, Ubuntu), а не згенеровано ШІ, щоб не було артефактів кирилиці. Дрібну помилку ШІ в адресі на етикетці виправлено ретушшю.
- Сторінку, тексти й логіку квізу написано разом із Claude; перевірено автотестом усієї воронки (Playwright) на мобільному та десктопі.
